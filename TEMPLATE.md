# QOTD Canonical Template

**Canvas:** 512×910, 30fps, 9:16.

**Timing:** 2s question / 8s countdown / 3s answer / 8s explanation / 3s CTA.

Question scene:
- CENTAURI ACADEMY header
- QUESTION OF THE DAY label
- large question
- four rounded answer cards

Countdown:
- same question/cards
- 8, 7, 6, 5, 4, 3, 2, 1
- PICK A, B, C, OR D
- progress bar decreases with the timer

Answer:
- correct card gets green border/background/accent
- ANSWER X label

Explanation:
- WHY?
- concise explanation in a bordered card

CTA:
- DID YOU GET IT?
- Practice this and hundreds more questions free.
- centauriacademy.app

The template is intentionally boring underneath the hood. That is a feature: hundreds of posts should look like one coherent product series.
